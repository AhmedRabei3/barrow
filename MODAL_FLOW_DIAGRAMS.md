```
┌────────────────────────────────────────────────────────────────┐
│                     MODAL CONTROL PATTERNS                     │
└────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────┐
│  PATTERN 1: useState (بسيط)     │
├─────────────────────────────────┤
│                                 │
│  const [open, setOpen] =       │

┌─────────────────────────────────┐
│  PATTERN 2: Zustand (معقد)      │
├─────────────────────────────────┤
│                                 │
│  const modal = useModal()       │
│                                 │
│  Button:                        │
│  onClick={() =>                │
│    modal.onOpen("create")       │

│                                 │

│  PATTERN 3: Props (متقدم)       │

│  />                            │
│                                 │
│  Modal Component:              │
│  const ContactModal = ({       │
│    isOpen,                     │
│    setOpen,                    │
│    ...props                    │

## 5. مخطط المسارات (Routes)

```
┌─────────────────────────────────────────────────────────────┐
│                    MODAL API ENDPOINTS                      │
└─────────────────────────────────────────────────────────────┘

الطلبات (Requests):
┌────────────────────────────────────────┐
│ POST /api/purchase                     │
│                                        │
│ الغرض: إنشاء طلب شراء أو إيجار         │
│ Purpose: Create purchase/rental req    │
│                                        │
│ Body: {                               │
│   itemId: string                      │
│   itemType: ItemType                  │
│   fullName?: string                   │
│   phoneNumber: string                 │
│   requestKind: "BUY" | "RENT"         │
│   note?: string                       │
│   offeredPrice?: number               │
│   buyerNote?: string                  │
│ }                                     │
│                                        │
│ Response: {                           │
│   success: boolean                    │
│   message: string                     │
│   requestId?: string                  │
│ }                                     │
└────────────────────────────────────────┘

إضافة السيارات (Add Cars):
┌────────────────────────────────────────┐
│ POST /api/cars/used_car                │
│                                        │
│ الغرض: إضافة سيارة مستعملة جديدة       │
│ Purpose: Add new used car              │
│                                        │
│ Body: FormData {                      │
│   brand, model, year, price,          │
│   color, gearType, fuelType,          │
│   description, sellOrRent,            │
│   rentType, status,                   │
│   mileage, repainted, reAssembled,    │
│   latitude, longitude,                │
│   address, city, state, country,      │
│   images (files)                      │
│ }                                     │
│                                        │
│ Response: {                           │
│   success: boolean                    │
│   message: string                     │
│   carId?: string                      │
│ }                                     │
└────────────────────────────────────────┘

إضافة العقارات (Add Properties):
┌────────────────────────────────────────┐
│ POST /api/realestate                   │
│                                        │
│ الغرض: إضافة عقار جديد                 │
│ Purpose: Add new property              │
│                                        │
│ Body: FormData {                      │
│   propertyType, bedrooms, bathrooms,  │
│   area, price, description,           │
│   sellOrRent, images (files),         │
│   location data                       │
│ }                                     │
└────────────────────────────────────────┘

إضافة عناصر أخرى (Add Other Items):
┌────────────────────────────────────────┐
│ POST /api/otherItems                   │
│                                        │
│ الغرض: إضافة عنصر آخر                  │
│ Purpose: Add other item                │
│                                        │
│ Body: FormData {                      │
│   title, category, price,             │
│   description, sellOrRent,            │
│   images (files), location            │
│ }                                     │
└────────────────────────────────────────┘
```

## 6. مخطط حالات المودال (State Diagram)

```
                    ┌─────────────────┐
                    │    INITIAL      │
                    │   isOpen=false  │
                    └────────┬────────┘
                             │
                    نقر على زر الفتح
                    Click open button
                             │
                             ▼

                    │     OPENING     │
                    │  showModal=true │
                    └────────┬────────┘

                    (رسوم متحركة)

                             │
                             ▼
                    ┌─────────────────┐
                    │      OPEN       │
                    │  showModal=true │

              ┌──────────────┼──────────────┐
              │              │              │

             │             │            │
         إرسال البيانات    إغلاق        إغلاق

         │showModal│             │
         │ =false │              │
         └───┬────┘              │
             │                   │
       (رسوم متحركة)             │

             │                   │

             │
             ▼

## 7. جدول الحقول حسب نوع المودال

| المودال             | الحقول المطلوبة                                                     | الحقول الاختيارية                                |
| ------------------- | ------------------------------------------------------------------- | ------------------------------------------------ |
| **ContactModal**    | • الاسم<br>• الهاتف                                                 | • ملاحظة                                         |
| **PurchaseElement** | • الهاتف                                                            | • السعر المقترح<br>• ملاحظة                      |
| **AddUsedCar**      | • الماركة<br>• الموديل<br>• السنة<br>• السعر<br>• الصور<br>• الموقع | • اللون<br>• وصف<br>• نوع الوقود<br>• نوع الناقل |
| **AddProperty**     | • نوع العقار<br>• المساحة<br>• السعر<br>• الموقع<br>• الصور         | • الأساسات<br>• الحمامات<br>• الوصف              |
| **SearchModal**     | متغير حسب المعايير                                                  | جميع المعايير اختيارية                           |
